🧾CRUD_MVC_UDEMY
Este es un pequeño proyecto CRUD hecho con PHP, MySQL y JavaScript usando el modelo MVC. También se usa Bootstrap para el diseño y SweetAlert2 para las alertas.
Me he basado en el repositorio PERSONAL_CRUD2 de Anders87x como guía-tutorial para aprender como funcionan las capas Modelo-Vista-Controlador y optimizar el uso
de recursos para mi sistema web

⚙️ Requisitos
- Servidor local (Se ha utilizado XAMPP)
- Navegador web (Usé Chrome)

📦 Instalación
- Clona este repositorio.
- Coloca la carpeta del proyecto en xampp/htdocs para que puedas accederlo desde el navegador con localhost.
- Abre XAMPP, inicia Apache y MySQL en este.
- Luego, en tu navegador, ingresa a phpMyAdmin (http://localhost/phpmyadmin)
- Ve a la pestaña Importar y selecciona el archivo crud2.sql que viene en este repositorio, en la carpeta docs.
- Esto creará automáticamente la base de datos llamada crud2 y la tabla tm_productos.
- Abre el proyecto en tu navegador
